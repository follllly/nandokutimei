# 難読地名カード

日本の難読地名を、地図から都道府県を選んでカードで覚えるアプリです。

- 地図で地方をタップして拡大し、都道府県を選ぶと出題が始まります（沖縄は1回のタップで開きます）
- 10問・30問・全件から選べます。苦手な地名と、まだ出ていない地名から順に出ます
- カードをタップすると読みが出ます。右へスワイプ（→キー）で「覚えた」、左へスワイプ（←キー）で「もう一度」
- 「覚えた」を重ねるほど、次に出るまでの間隔がのびます（1日・3日・7日・16日・35日）。「もう一度」で最初に戻ります
- 答えの面に、県の場所を示す小さな地図と、由来などの豆知識（ある地名のみ）が出ます。「地図で見る」でGoogleマップを開けます
- 「地図を進み具合で色分け」で、県ごとの覚えた割合を地図の色で見られます
- 記録は、このブラウザの中にだけ保存されます
- 地図のデータ: Geolonia
- 地名データの多くは、Wikipediaの各都道府県の難読地名一覧（CC BY-SA 4.0）をもとにしています。市町村が一覧から特定できなかった沖縄の地名は、郡の名前だけを入れています
